Спецификация приложения: WhisperKey
1. Концепция продукта
Легковесная, нативная утилита для macOS (App Bundle), обеспечивающая системный голосовой ввод с нулевой задержкой. Приложение выступает «умной оболочкой» для whisper.cpp, обеспечивая стриминговую передачу звука и управление состояниями без создания временных файлов на диске.

2. Технический стек
Оболочка и UI: Swift, AppKit (Status Bar, Floating Overlay).

Аудио-движок: AVFoundation (захват микрофонного потока в RAM).

Нейросеть: whisper.cpp (динамическая линковка с libwhisper.dylib из Homebrew для автоматического получения обновлений движка).

Ввод текста: Эмуляция клавиатурного ввода через CGEvent.

Сборка: Swift Package Manager (SPM), локальная сборка с Ad-hoc подписью (без Developer Account).

3. Пользовательский интерфейс (UI/UX)
3.1. Меню в статус-баре (Трей)
Основной пульт управления приложением. При клике на иконку разворачивается меню:

Микрофон: * Выпадающий список всех доступных аудиоустройств.

Поведение по умолчанию: Приложение всегда перехватывает текущий системный микрофон при старте или переключении (например, при подключении наушников).

Управление моделями:

Активная модель: Индикатор текущей загруженной модели (например, Medium).

Локальные (Скачанные): Список моделей, уже доступных на диске.

Доступные для загрузки: Список официальных моделей (Tiny, Small, Large-v3 и т.д.), которых еще нет. Клик по такой модели запускает скачивание с отображением прогресс-бара прямо в меню.

Настройки: Указание папки для хранения/чтения моделей (с использованием Security-Scoped Bookmarks).

Выход (Quit).

3.2. Плавающий HUD-Оверлей (Индикатор состояний)
Минималистичное, полупрозрачное окно поверх всех окон, которое появляется только в момент взаимодействия, чтобы давать визуальный фидбек.

🎙️ Запись: Отображается, пока пользователь удерживает горячую клавишу. Означает, что микрофон активен и стримит данные.

⏳ Распознавание: Появляется в момент отжатия клавиши. Означает, что Whisper обрабатывает аудиопакет.

✅ Вставка: Микро-анимация (на долю секунды), подтверждающая, что текст отправлен в активное окно.

4. Внутренняя логика и Машина состояний (State Machine)
Приложение жестко контролирует использование ресурсов через конечный автомат:

Idle (Сон): * Модель выгружена из оперативной памяти. Оверлей скрыт. Потребление RAM минимально (~30 МБ).

Loading (Инициализация): * Срабатывает при первом нажатии на хоткей. Асинхронная загрузка .bin файла в память в фоновом потоке, чтобы не блокировать UI.

Recording (Запись потока): * AVAudioEngine захватывает звук и напрямую через пайп (или прямые вызовы C-API) скидывает буферы в движок Whisper. Никакого взаимодействия с накопителем (SSD/HDD).

Transcribing (Распознавание): * Остановка аудиопотока. Движок генерирует текст.

Pasting (Вывод): * Перехват ответа и вставка строки в то место, где находится системный курсор.

Cooldown (Ожидание): * После вставки запускается таймер на 30 минут. Если за это время диктовка не использовалась — вызывается whisper_free(), 1.5 ГБ памяти возвращаются системе, приложение переходит обратно в состояние Idle.

5. Безопасность и Права (TCC)
Приложение имеет Info.plist с ключом NSMicrophoneUsageDescription.

При первом запуске macOS штатно запрашивает доступ к микрофону и чтению папки с моделями.

Права привязываются к App Bundle, исключая «молчаливые блокировки» фоновых процессов.
